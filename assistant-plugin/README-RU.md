# NewCatroid Assistant 0.6.0

Добавлены частичная отправка проекта и проверка, что открыт нужный настоящий проект NewCatroid. Сохранены функции 0.5, PNG, старый формат .nplug и format-1 JSON-патчи.

## Обновление

1. Дождись успешного Cloudflare Build для ветки newcatroid-cloudflare. Сервер 0.6 теперь состоит из двух JS-модулей — newcatroid-worker.js и sync-store.js; GitHub/Wrangler собирает их вместе. DB, адрес и секреты остаются прежними.
2. Удали только старый плагин помощника, установи NewCatroid-Assistant-0.6.0.nplug и полностью перезапусти NewCatroid. Проекты и приложение не удаляй.
3. Открой нужный проект, останови игру, нажми «Отправить состояние на сервер». Первая отправка полная, следующие обычно частичные. Панель показывает режим, число отправленных частей и размер.
4. Если сервер ожидает другой проект, вернись к нему либо вручную отправь состояние новой игры для намеренного переключения.

Termux: заменить server.py и положить рядом sync_store.py из архива, затем запустить прежней командой. Каталог ~/.newcatroid-bridge не удалять. Предыдущие ключи и состояние сохраняются. Старые плагины продолжают использовать полный экспорт.

## Как работает

Изменённый скрипт отправляется отдельно, без текста остальных скриптов. Изменения структуры, ресурсов и сцен попадают в соответствующие части XML и метаданные. Полный XML остаётся на сервере доступен через прежние инструменты. XML собирается без переформатирования: общий SHA-256 должен точно совпасть. Потеря базы, новый сервер или новая личность проекта вызывают безопасную полную пересинхронизацию.

Личность проекта учитывает его каталог и ID первой сцены. Одного одинакового названия недостаточно. Переименование каталога/смена первой сцены меняет ID и требует новой полной синхронизации. Локальная сериализация проекта для поиска изменений всё ещё выполняется; экономятся передаваемые данные. При чрезвычайно большом числе скриптов используются более крупные части вместо отдельных скриптов.

## Проверки

Java-компиляция с Android API; 59 проверок плагина/каталога/синхронизации. 51 проверка Worker, в том числе с настоящим JSON, сформированным Java-экспортёром. 15 прежних тестов Python-сервера и 5 новых проверок частичного экспорта. Повторены 2 проверки хранилища NewCatroid.

В синтетическом примере полный запрос занимал 653329 байт, после изменения одного небольшого скрипта — 2465 байт. Это пример теста, не обещание такого же коэффициента для любой игры.

На настоящем Android ещё нужно проверить установку, полный→частичный экспорт реального проекта, переключение игр, восстановление базы после очистки сервера, сообщения об ошибках и старые игровые функции. Здесь Android не запускался.
