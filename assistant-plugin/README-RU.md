# NewCatroid Assistant 0.5.0

Плагин с прежним packageName и форматом .nplug. Добавлены сцены, перенос/переименование/удаление спрайтов, смена событий и выборочное редактирование скриптов, освещение и блоки постоянного хранения данных. PNG из 0.4 поддерживаются.

## Обновление

1. Сначала обнови bridge. Cloudflare: исходники находятся в прежней ветке newcatroid-cloudflare, папка cloudflare-bridge, имя Worker purple-resonance-01d7. Дождись успешного деплоя. D1 и три секрета оставь прежними. Для другого Worker сохрани его действующее имя/привязки в wrangler.jsonc.
2. В NewCatroid удали **только старый плагин помощника**, импортируй NewCatroid-Assistant-0.5.0.nplug и полностью перезапусти приложение. Само приложение и проекты не удаляй. Адрес и ключ устройства используют прежнее хранилище настроек.
3. Открой проект, останови игру и отправь состояние. В project.json будет версия 0.5.0 и request_id. Для следующих изменений ассистент должен запросить свежий экспорт через bridge.
4. Получи патч, открой предпросмотр и примени. Результат отправится обратно на сервер. При отсутствии связи отчёт сохраняется на телефоне.

Termux: останови старый server.py, замени его новым из архива и запусти прежней командой, например `python server.py --enable-link-access`. Не удаляй каталог ~/.newcatroid-bridge: там ключи, состояние и история. Python использует только стандартную библиотеку. Cloudflare и Termux — альтернативные серверы, запускать оба не нужно.

## Ограничения

Перенос обычного спрайта сохраняет тот же объект и ID его данных. Фон и групповые/специальные спрайты этой операцией не переносятся. Неразрешимые ссылки и конфликты отклоняются, вместо молчаливого удаления связей. В патче переноси/переименовывай спрайт до добавления новых PNG. Копируются только нужные ресурсы; старые сохраняются для восстановления. Переименование сцены копирует её каталог. XML-резервная копия не заменяет полный архив проекта. Журнал новых ID действует с версии 0.5.

Каталог поддерживает проверенные адаптеры и дополнительно обнаруженные простые блоки освещения. Если неизвестный класс требует неадаптированных объектных полей, он не объявляется поддерживаемым. Пользовательские функции и входы пользовательских блоков можно сохранить нетронутыми, но создавать новые формулы с ними пока нельзя.
