# NewCatroid Runtime Audio 1 + Assistant 0.7.0

Реализация добавляет в NewCatroid системный выбор MP3/OGG во время игры, постоянное хранилище проекта и проигрыватель. Одного .nplug недостаточно: PluginEntry предоставляет только onLoad(Context), а новые сериализуемые блоки, функции и обработчики StageActivity принадлежат приложению.

В категории «Звук» есть восемь вариантов RuntimeAudioBrick с выбором команды: выбрать, импортировать, воспроизвести, пауза, продолжить, остановить, позиция и громкость. Каждый вариант записывает результат в указанную переменную и ждёт завершения операции. Для кнопки «Добавить музыку» используйте PICK -> проверка результата -> IMPORT -> проверка результата -> сохранение ID с уровнем. Пример фрагментов JSON: assistant-plugin/examples/runtime-audio-bricks.json. Это не готовый патч конкретной игры: для него нужен свежий экспорт из обновлённого приложения.

Результат выбора: selection:UUID / cancelled / error:CODE. Результат импорта: audio:UUID / cancelled / error:CODE. Управление: ok / error:CODE. ID audio:UUID сохраняйте вместе с уровнем; selection:UUID и URI телефона сохранять нельзя. Импортированный файл остаётся после удаления исходника и перезапуска. Состояние переменной/уровня нужно сохранять существующими блоками записи на устройстве.

Функции: AUDIO_NAME(id), AUDIO_DURATION(id), AUDIO_POSITION(id), AUDIO_EXISTS(id), AUDIO_ERROR(), AUDIO_STATE(). Время — секунды, громкость — 0–100. Один проигрыватель на сцену; переход в другую сцену останавливает музыку. Фон временно приостанавливает её; явная пауза сохраняется. Завершение проекта освобождает проигрыватель. Отмена/повторные нажатия обрабатываются отдельно. STOP прерывает незавершённую операцию.

Файлы сохраняются внутри project/files/imported-audio-v1. Полная копия/.catrobat переносит их и сохраняет ID. Передача только JSON уровня музыку не переносит: AUDIO_EXISTS возвращает 0, PLAY — error:MISSING_AUDIO. В интерфейсе игры этот результат нужно показать как «Музыка отсутствует». Не удаляются треки, на которые могут ссылаться другие уровни. Незавершённые импорты в ZIP не попадают. Лимит файла — 64 МиБ.

Assistant экспортирует только метаданные импортированной музыки. На bridge аудио не отправляется; сервер 0.6.0 подходит, URL и ключи менять не нужно. На старом NewCatroid плагин продолжит работать, но не объявит новые блоки и функции доступными.

## Обновление

1. Сделайте полный экспорт проекта .catrobat, содержащий ресурсы. Обновление приложения не выполняется этим архивом исходников.
2. APK собран как Danvex Debug, версия 2.2.0-audio.1, ARM64. Подпись — репозиторный debug.keystore. Если Android сообщает о несовместимой подписи, не удаляйте установленное приложение ради обновления: для обновления поверх него нужен исходный ключ подписи, либо отдельная тестовая установка с другим applicationId и импортом копии проекта.
3. Удалите только прежний плагин Assistant, импортируйте NewCatroid-Assistant-0.7.0.nplug и полностью перезапустите приложение. Не удаляйте приложение/проекты. Формат .nplug и packageName плагина сохранены.
4. Откройте остановленный проект и отправьте свежий экспорт состояния. Появятся RuntimeAudioBrick и точные сигнатуры AUDIO_* от установленного хоста. Старый экспорт не подтверждает поддержку новых блоков.
5. Для конкретного Креатора добавление кнопки/сохранение ID выполняется проектным патчем после этого экспорта. В исходниках приложения нет жёсткой зависимости от названия или внутренностей вашей игры.

## Проверки

Выполнены локально: 30 проверок постоянного хранилища/ZIP, 32 проверки сеанса с заменами Android/MediaPlayer, 21 проверка адаптера аудиопатчей и 59 прежних проверок транзакций Assistant. Проверена компиляция новых классов с Android API 34/GDX и всех исходников .nplug. Проверки с заменами проигрывателя не подтверждают работу настоящего декодера или окна SAF.

Добавлены, но НЕ запускались на устройстве: RuntimeAudioDeviceTest (настоящие MP3/OGG, pause/resume/seek, удаление исходника, загрузка ID новым хранилищем, повреждённый файл и отмена). Синтетические тестовые тоны генерировались FFmpeg, 440 Гц, 3 секунды, без чужой музыки. Полный список ручных сценариев — checks/runtime-audio/ANDROID-CHECKLIST.md. Окно выбора, фон, поворот/уничтожение Activity и полный перенос проекта на другой телефон ещё нужно проверить на Android.

## Исходники и сборка

База: serikmain49-rgb/NewCatroid, коммит f1815f9d47393d282eaa249af23a83fea8745c65. Рабочая ветка: runtime-audio-import. ZIP исходников содержит изменённые файлы и source.patch; он накладывается на эту базу, не является полной копией большого репозитория.

Сборка: JDK 17, Android SDK 34 / Build Tools 34.0.0, NDK 26.1.10909125, CMake 3.22.1, Gradle 8.7.

```sh
./gradlew --no-daemon --max-workers=1 :catroid:assembleDanvexDebug -x lint -x test -Dorg.gradle.jvmargs=-Xmx5g -Dorg.gradle.parallel=false -Pkotlin.compiler.execution.strategy=in-process -Pandroid.injected.build.abi=arm64-v8a
```

Защита request_id, SHA-256, project_id, резервные копии, очередь и подтверждение применения остаются прежними. Ни приложение, ни проект на телефоне этим действием автоматически не обновлены.
