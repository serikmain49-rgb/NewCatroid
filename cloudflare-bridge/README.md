# NewCatroid Bridge — Cloudflare Workers + D1

Мост между Android-плагином NewCatroid Assistant 0.2/0.3 и ChatGPT.
Работает без постоянно запущенного Termux. Совместим с прежними REST-командами и четырьмя MCP-инструментами.
Состояние и очередь патчей сохраняются в D1. Патчи применяются только вручную на телефоне.

## Подключить репозиторий

В Cloudflare открой существующий Worker `newcatroid-bridge` → **Settings → Builds → Connect**.
Выбери GitHub и репозиторий `serikmain49-rgb/NewCatroid`.

| Поле | Значение |
| --- | --- |
| Worker name | `newcatroid-bridge` |
| Production branch | `newcatroid-cloudflare` |
| Root directory | `cloudflare-bridge` |
| Build command | `npm run check` |
| Deploy command | `npm run deploy` |

Cloudflare установит npm-зависимости из lock-файла. Для локальной установки: `npm ci`.
Если Worker ещё не создан: Workers & Pages → Create application → GitHub, затем те же настройки.
Это Worker, не статический сайт Pages. APK и Gradle собирать не требуется.
После подключения запусти Deploy/Retry build, если сборка не началась автоматически.

## База D1

Wrangler поддерживает автоматическое создание ресурсов. Конфигурация объявляет привязку `DB` без ID.
При развёртывании существующего Worker Wrangler должен сохранить ранее подключённую к `DB` базу.
Если привязки ещё нет, создаст базу. При следующих развёртываниях связь сохраняется.
После первого развёртывания проверь **Bindings → DB**. Не удаляй существующую базу.
Если вместо уже созданной `newcatroid-db` подключилась другая пустая база, можно явно указать
`database_name` и `database_id` нужной базы в `wrangler.jsonc`.
ID базы не является паролем. Секретные ключи в GitHub добавлять нельзя.
Если сборка не имеет разрешения создать D1, подключи ранее созданную базу под именем DB в панели
и повтори сборку; для управления D1 сборочному API-токену могут потребоваться соответствующие разрешения.

## Три секретных ключа

1. После Deploy открой адрес Worker через Visit.
2. Разверни **Первый запуск: создать ключи** и нажми **Создать три ключа** один раз.
3. Сохрани значения у себя. Генерация происходит локально в браузере.
4. В Cloudflare: Worker → Settings → Variables and Secrets → Add.
5. Создай три записи типа **Secret**, имена строго:
   - `DEVICE_TOKEN`
   - `ASSISTANT_TOKEN`
   - `MCP_LINK_SECRET`
6. Вставь соответствующие значения и нажми Deploy.

До настройки DB и ключей защищённые запросы возвращают 503; стартовая страница доступна.
Ключи должны быть разными, 32–128 символов: латиница, цифры, `_` или `-`.
Кнопка генерации не сохраняет значения на сервере и не заменяет существующие ключи.
Не публикуй их в репозитории, чатах, скриншотах или логах.

## Телефон

В меню кубика → настройки сервера:
- URL: основной HTTPS-адрес Worker, без `/mcp/...`.
- Ключ устройства: значение `DEVICE_TOKEN`.
- Включи соединение и отправь состояние проекта. Игра должна быть остановлена.

Переустановка Assistant 0.3 не требуется. Последнее состояние из Termux не переносится автоматически:
отправь его заново с телефона. Ранее ожидавшие патчи тоже не переносятся.

## ChatGPT

Измени подключение NEWCATROID на адрес вида:
`https://<адрес-worker>/mcp/<значение-MCP_LINK_SECRET>`.
Выбери **Без аутентификации**: в этом режиме доступ защищён секретным путём.
Полный адрес является секретом. Альтернативный endpoint `/mcp` поддерживает
`Authorization: Bearer <ASSISTANT_TOKEN>` для клиентов, умеющих задавать этот заголовок.
MCP protocol: `2025-03-26`, stateless Streamable HTTP с JSON-ответами.

Инструменты: `bridge_status`, `request_state`, `read_project_file`, `submit_patch`.
Запрос состояния асинхронный: нужно дождаться снимка с совпадающим request_id и прочитать все четыре файла.
Сайт позволяет проверить состояние с ASSISTANT_TOKEN и вручную поставить JSON-патч в очередь.
Секретные значения не вшиты в исходный код и не отображаются сервером.

## Ограничения и проверки

- Бесплатные квоты Cloudflare сохраняются; это не гарантия бесперебойности 24/7.
- На Free есть лимит процессорного времени Worker; очень большие снимки могут его превысить.
- Лимит HTTP-тела/снимка: 4 MiB; патча: 1 MiB; 1–200 операций.
- Изображения, звуки и модели не передаются. Открывать проект и применять патчи нужно в NewCatroid.
- Состояние хранится порциями ниже лимита строки D1 и заменяется транзакцией.
- Хеш XML проверяется; устаревшие патчи отклоняются и удаляются из очереди после смены снимка.
- Сайт не сохраняет ключи в localStorage, не содержит аналитики или внешних скриптов.
- Не включай логирование полных URL: MCP-путь содержит секрет.

Локально: Node.js 22+ и Python 3, `npm test`.
21 проверка с SQLite-адаптером D1: авторизация, роли, Origin, SHA, Unicode, чтение по частям,
очередь, устаревшие патчи, несовпадающие request_id и MCP.
Проверка сборки: `npm run check`, `npm run deploy -- --dry-run`.
Локальные проверки не заменяют проверку в реальном Cloudflare и NewCatroid.
